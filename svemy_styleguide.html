Description

This document serves as a comprehensive style guide and reference template for creating SVEMY-branded PDF reports. It defines specifications for typography, color palettes, layout components, and design elements to ensure consistency across all SVEMY Construction Ltd. documentation.

Purpose

The style guide defines the required visual and structural standards for all SVEMY documents. It specifies the approved fonts, colors, layouts, and formatting rules to ensure consistent, accurate, and professional presentation across all reporting and technical materials.

Document Features & Functionality

This template includes advanced automated features for document generation:

  • Automatic Pagination — Intelligent content splitting across pages with overflow detection
  • Dynamic Table of Contents — Auto-generated navigation with page number references
  • Content Protection — Prevents splitting of tables, code blocks, and other intact elements
  • Automatic Page Numbering — Dynamic page numbers in footers and navigation links
  • Navigation Reordering — Automatically matches navigation order to actual content structure
  • Multi-page Sections — Handles sections that span multiple pages with continuation headers
  • Error Handling & Validation — Comprehensive error checking with fallback mechanisms
  • Print & PDF Ready — Optimized for print preview and PDF export
  • Dynamic Content Updates — Automatic repagination support for dynamically modified content
  • Section Positioning — Ensures correct order (Cover → Description → ToC → Content)

    Components

    Callout Blocks

    For notes and status messages set apart from the text. Light fill, colored rule on the left, square on that side.

    Note

    Use this neutral style for general notes, assumptions or remarks that carry no status.

    Info callout

    Use this style to highlight additional context or background information.

    Success callout

    Use this style to indicate that a key milestone or KPI has been successfully achieved.

    Warning callout

    Use this style to flag risks, constraints, or items that require attention.

    Danger callout

    Use this style for critical issues or blockers that impact project success.

    Quotes

    For quotations and key messages. Geist Italic with a yellow bar on the left.

    “Quotation or key message, set apart to stand out from the surrounding text.”

    Code Blocks

    For file names, parameters and structured data. Monospace 9 pt on a gray fill. 

    function calculateBudget(planned, actual) {
  const variance = actual - planned;
  const percentage = (variance / planned) * 100;
  return { variance, percentage };
}

    Badges

    For short statuses. Fixed size: 5 mm high, 2 mm side padding, 1.3 mm dot, 1.2 mm gap. Sentence case.

    Completed Use for completed tasks, successful status, or positive outcomes.

    Pending Use for items not started, on hold, or waiting for a decision.

    Layout & Grid

    A consistent grid keeps content aligned across every document.

    Corners: 4 px on every table, image and filled block, including badges and inline code. Exceptions: checkboxes use 2 px, as 4 px would make them look round; callouts round the right side only.

    Single Column

    Full-width content

    Overview

    Full-width content provides space for detailed explanations and uninterrupted reading.

    Reports, narrative text and wide tables.

    Two Columns

    Paired content

    Content alignment

    Align both columns at the top to create a clear starting point.

    Column spacing

    Keep a consistent gutter so adjacent text remains visually separate.

    Image pairs and balanced comparisons.

    Three Columns

    Short content blocks

    Hierarchy

    Use short headings to introduce each block.

    Text length

    Keep paragraphs brief for comfortable reading.

    Consistency

    Apply the same internal spacing across all columns.

    Summaries and supporting information.

    Four Columns

    Metrics and brief labels

    Labels

    Keep headings short.

    Content

    Use concise descriptions.

    Spacing

    Maintain equal gutters.

    Alignment

    Align all blocks at the top.

    Keep content concise; avoid long paragraphs.

    def calculate_quality_score(inspections):
    passed = sum(1 for i in inspections if i.status == 'passed')
    total = len(inspections)
    score = (passed / total) * 100
    return {
        'score': round(score, 2),
        'passed': passed,
        'total': total,
        'status': 'acceptable' if score >= 95 else 'review_required'
    }
